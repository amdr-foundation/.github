# Contributing to AMDR Foundation repositories

Thank you for helping. These repositories hold course materials and teaching exemplars for the Foundation's programs.

## Licence of contributions

Course materials (lab sheets, guides, rubrics, starter workflows, documentation) are licensed under Creative Commons Attribution-NonCommercial-ShareAlike 4.0 (CC BY-NC-SA 4.0). By opening a pull request you agree that your contribution is released under the same licence as the repository it lands in. Each repository carries its own `LICENSE.md`; GitHub does not inherit licences at the organisation level, so check the file in the repository you are changing.

## How to contribute

1. Open an issue first for anything larger than a typo fix, so we can agree on scope.
2. Fork, branch from `main`, and keep each pull request to one change.
3. For n8n workflow JSON: export with credentials removed, strip personal data, and note the n8n version you tested on.
4. Write in plain language. Learners are non-technical adults; avoid jargon without a definition.
